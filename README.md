# Duck Hunts: The Ducks Strike Back

A retro, NES-style browser game where the duck has the gun. Fly over a scrolling
field, shoot the hunters, or swoop in with the knife.

**Play it:** https://avgunaa.github.io/duck-hunts/

## Controls

| Action | Keyboard / mouse | Touch |
| --- | --- | --- |
| Fly | Arrow keys or WASD | D-pad |
| Shoot | Click | A button, or tap the screen |
| Knife swoop | Space or right-click | B button |
| Pause | P | PAUSE |
| Mute / CRT lines / Zapper flash | M / C / F | |

## How it works

- Each round has 10 hunters. Hit enough of them to meet the quota and move on.
- Later rounds scroll faster and send more hunters at once (up to 5).
- Hunters hide behind tree trunks and up in the leaves, so watch for falling leaves.
- Chain hits for a combo multiplier, and pop balloons for hearts, shells, a shield
  or double score.
- High scores are stored in your own browser.

## Running locally

The whole game is `index.html`. Open it in any browser; there is nothing to build.
